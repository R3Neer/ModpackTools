# ModpackTools 5.0.0 — Native, faster, PowerShell-free

ModpackTools now runs as a native Windows x64 application, with faster startup and local inventory commands.

- Use `modpack` from Nushell without PowerShell.
- Install and update through the native installer.
- Keep the familiar command interface, human-readable output and structured `--no-human` results.
- Benefit from verified packages, controlled updates and recovery safeguards.

The installation format has changed. Follow the [native installation instructions](https://github.com/R3Neer/ModpackTools/blob/v5.0.0/README.md#installation) when upgrading from 4.x.

## Windows paths

Long executable paths are supported by the native hosts and Nushell bridge.
For external tools, Windows may require a shorter working-directory name.
ModpackTools uses an existing 8.3 name only after verifying the physical directory
identity. If no usable name exists, it reports the affected path and asks for a
shorter native state directory. It does not change Windows settings or create
aliases. Preserve pending recovery state before relocating that directory.
