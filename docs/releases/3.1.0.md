# ModpackTools 3.1.0

This release adds `modpack remove` for installed mods, resource packs and shaders,
including local files and Packwiz-managed content.

```powershell
modpack remove sodium iris --dry-run
modpack remove 3 7 --project my-pack
modpack remove fabric-api --cascade --autoremove --dry-run
```

## Changes

- Resolve a complete batch by installed name, ID, filename or saved inventory
  number. Ambiguous or invalid selections cancel the whole operation.
- Block removal that breaks declared required dependencies. `--cascade` includes
  affected dependents, respecting the shared validator's alternatives, conditions
  and client/server scopes.
- `--autoremove` cleans automatic dependencies left unused by this removal,
  including cycles. Shared dependencies, explicit content, pins, local files and
  unrelated pre-existing orphans are retained. Incomplete verification blocks
  automatic cleanup; omit this option when removing explicit targets in that case.
- Preview the full content and file plan before confirmation, defaulting to no.
  `--yes` skips the prompt; `--dry-run` leaves project files unchanged. A changed
  plan is rejected before commit.
- Use the existing transaction, rollback and recovery engine. Remove associated
  editorial metadata, refresh Packwiz and update active resource-pack order while
  preserving configs, worlds, category definitions and the previous build.
- Reject removal of pinned items, altered local Packwiz artifacts, shared file
  ownership and paths outside the content directory.
- Extend the R3CLI command catalogue, inventory guidance, README and architecture
  documentation. The bundled renderer and public PowerShell exports are unchanged.

## Validation

- All 202 Pester 4.10.1 tests pass, covering removal, dependency graphs, transaction recovery,
  selector handling, confirmation and R3CLI presentation.
- Isolated installation verifies package hashes, custom-theme preservation,
  rejected-upgrade recovery, every command's help in fresh processes and plain
  redirected output.
- Live integration exercises the installed module with real Modrinth JARs and
  Packwiz. Removing a local owner also cleans the now-unused Lithium dependency,
  preserves Sodium and exports an MRPack containing only the retained mod.

Dependency checks validate declared metadata; they do not launch Minecraft or
prove runtime mod compatibility. Rebuild the pack after removing content.
