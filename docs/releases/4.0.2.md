# ModpackTools 4.0.2 — Quieter command output

ModpackTools 4.0.2 removes banners that repeated the command already entered.

## Changes

- Project, configuration, search, build, update, diff, category, version, and doctor output begins with useful content rather than a command banner.
- Project and item identities remain visible as compact headings or key-value rows where they distinguish the result.
- Section headings within longer reports remain in place.

## Compatibility

Command syntax, structured output, project data, and installation format are unchanged.
