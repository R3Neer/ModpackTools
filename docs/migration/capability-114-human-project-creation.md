## Real Go network finding

The first forced HTTP(S) proxy test intentionally blocked outbound requests and
showed that pinned real Go Packwiz init still reads Mojang's version_manifest.json
even with explicit versions. This is not an offline success. The final harness
expects Build.ProcessFailed under blocked proxies, proves no destination or
retained creation workspace, restores proxies and then permits the metadata read
for the successful actual-Go creation. A Windows backslash glob in an intermediate
harness attempt failed; it was replaced by literal directory enumeration. Product
code/executable did not change after these harness discoveries. No publication.
This external metadata cost must remain separate in final performance samples;
any optimization to native generation needs another evaluated contract/checkpoint.
