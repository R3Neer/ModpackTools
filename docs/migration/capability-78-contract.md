# Capability78: public native resource-pack operations

CLI preserves parser and priority, structured transaction and (non-dry-run only)
resource_packs rows, active first and remaining inactive in inventory order. Build
all output before pending publication with the shared reserved transaction buffer.
No postcommit inventory re-read or fallible serialization of previously unknown
data. Core returns owned order and composed resource view from its existing stage
snapshot, rebasing inactive metadata paths to protected root; no extra JAR scan.
Nu owns machine resource-pack commands, validates transaction and complete resource
rows, unwraps transaction, preserves parent state and never retries legacy after
failure. Existing commands omit the new optional envelope field as before.

Finite public original/native cases: enable including full resource rows, disable
dry-run omission, forbidden position before missing project; one actual Nu enable.
Native core defaults, protocol/version and fresh Nu regression plus both reviewers.
