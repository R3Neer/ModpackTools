# Capability 96: public structured build and Nushell

The native host dispatches build to the accepted complete transaction95. Grammar
and bare-option diagnostics precede project selection and configuration reads.
The original machine contract is retained: dry-run returns only data.health;
a published build returns health, resource_packs and build statistics, with no
invented inventory, project, summary or reference-number assignment.

All success bytes are prepared before publication. Bounded postcommit diagnostics
remain success results. The explicit --open option invokes Explorer after a
successful non-dry build; an Explorer launch failure becomes a diagnostic rather
than misreporting an already committed build as failed. Dry-run never opens it.

Nushell dispatches machine build directly to the native host and validates health,
dry-run/result shape, statistics and resource fields before unwrapping the legacy
machine value. Invalid replies and native errors are terminal. Human/help and
other commands still require their own closure; this checkpoint does not remove
the legacy installation or activate personal shell changes.
